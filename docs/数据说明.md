# 数据说明

> 关联:COMPETITION.md §8 数据合规红线、docs/元数据组织方案.md(M1)。

## 1. 数据来源

- 数据集:比赛主办方提供的 **"Agentic智能问数在客户营销场景的应用数据集"**(券商客户营销场景)。
- 形态:8 张 UTF-8 CSV + `表描述.sql`(GBK 编码)+ `Q&A.xlsx`(空壳,不依赖)。
- 本项目将 CSV 载入只读 SQLite `enterprise.db`(91MB),评测/演示全部只读运行(mode=ro + PRAGMA query_only=ON),不写库。

## 2. 每表每字段含义(以库为准,已与 表描述.sql 校对)

### dim_branch 营业部维表(312 行)
| 字段 | 含义 |
|---|---|
| data_dt | 日期(20260531 单快照) |
| org_id | 营业部 ID |
| org_name | 营业部名称(**含 `****` 脱敏**) |
| up_org_id / up_org_name | 上级分公司 ID / 名称(27 家分公司) |

### dim_public 编码字典(155 行)
`code` + `code_type_id` + `describe`。七类:100 客户等级、200 账户状态、300 证件类型(无表引用)、400 风险等级(无表引用)、500 性别、600 学历、700 职业。客户表实际引用 100/200/500/600/700。

### dim_product 产品维表(334,694 行)
`prdt_id`(产品 ID)、`prdt_name`、`sor_prdt_id`、`market_id`、`prdt_type_id/prdt_type_name`(二级分类,57 类)、`up_prdt_type_id/up_prdt_type_name`(一级分类,11 类;注意 PT090000/PT070000 一级名多义,按 ID 归类)。

### ads_cust_info_d 客户主档(500 行)
`data_dt`(仅 20260531)、`pty_id` 客户号、`sor_pty_id` 经纪客户号(疑似个人关联标识,演示不展示)、`cust_lvl_cd` 客户等级码、`cust_status` 账户状态码、`cust_type`(全 P 个人)、`prov_name/city_name`、`birth_dt`、`cust_age`、`name`(**已脱敏,如"某***"**)、`gender_cd/edu_cd/prof_cd` 性别/学历/职业码、`org_id` 所属营业部。

### dwd_cust_hold_d 客户持有日事实(408,150 行)
`data_dt`(20260101~20260331,90 天)、`pty_id`、`prdt_id`、`sys_source`(nm 普通/fc 信用)、`ccy`(0 人民币/1 美元/2 港币)、`hold_cnt` 持有份额、`mkt_val` 持有市值。

### dwd_cust_tran_d 客户买卖日事实(39,060 行)
`data_dt`(20260105~20260331,56 交易日)、`pty_id`、`prdt_id`、`sys_source`、`ccy`、买入侧 `buy_cnt 次数/buy_mnt 数量/buy_rake 佣金/buy_amt 金额/buy_fare 费用`、卖出侧 `sell_*` 同构。

### dws_cust_aset_d 客户资产日汇总(43,684 行)
`data_dt`(90 天)、`pty_id`、`nm_tot_aset` 普通总资产、`nm_bal` 普通现金、`fc_pur_aset` 信用净资产、`fc_bal` 信用现金。总资产口径 = nm_tot_aset + fc_pur_aset。

### dws_cust_fin_d 客户资金流动日事实(4,892 行)
`data_dt`(56 天)、`pty_id`、`sys_source`、`cash_in/cash_out` 现金进出、`tran_in/tran_out` 证券转入转出、`assign_in/assign_out` 指定转入转出。

## 3. 预处理流程

1. 读 8 张 UTF-8 CSV(`表描述.sql` 为 GBK,读取用 gbk/gb18030)。
2. 数值列(金额/份额/数量/年龄)转 REAL,ID 与日期转 TEXT(`data_dt` 保持 YYYYMMDD)。
3. 载入 SQLite,建 pty_id / 产品名索引;行数与源 CSV 一致(dim_branch 312 / dim_public 155 / dim_product 334694 / ads_cust_info_d 500 / dwd_cust_hold_d 408150 / dwd_cust_tran_d 39060 / dws_cust_aset_d 43684 / dws_cust_fin_d 4892)。

## 4. 脱敏情况

- 客户姓名 `name`:已脱敏(如"某***")。
- 营业部/分公司名称:含 `****` 脱敏。
- `sor_pty_id`(经纪客户号):疑似个人关联标识,演示/报告/截图一律不出现该列。
- 演示输出、报告截图、视频素材中的客户明细一律聚合到看不出个体。

## 5. 使用限制

- 数据仅用于本次比赛评审与演示;禁止联网抓取补充数据、禁止引入外部真实个人信息。
- 库只读运行;任何评测/演示不得写库。
- 300 证件类型 / 400 风险等级仅有词典、无引用表,"风险等级分布"类问题按不可答处理。
