# 模型/算法说明

> 关联:COMPETITION.md 成果物 #5;覆盖 NLU/SQL 生成/校验/修复各环节的方法、实现与参数。

## 1. 总体架构

9 阶段状态机(见 text2sql.py docstring):理解 → 检索 → 计划 → 检查计划 → 生成 SQL → 安全校验 → 执行 → 检查结果 → 解释。每阶段输出写入 Trace;LLM 阶段异常经 `_safe_stage` 兜底为友好错误,不崩溃。

## 2. NLU(阶段 1 理解)

- 方法:单次 LLM 结构化抽取,输出 JSON:`answerable / summary / metrics / dimensions / filters / time_range / assumptions / missing(required|optional) / question_specificity(clear|vague)`。
- JSON 解析:`extract_json` 容错(剥 markdown、正则兜底);失败重试 1 次并带"精简输出"提示。
- 追问判据(程序化,不依赖 LLM 兜底):clarify=True 且 (missing_required 非空 **或** question_specificity=vague **或** 指标/维度/筛选/时间全空) → 强制 needs_clarification;E2 路径(有明确指标)不受影响。

## 3. 检索与计划(阶段 2-4)

- 检索:LLM 挑选相关表列,程序化校验表/列真实存在(库元数据 `get_table_meta`)。
- 计划:LLM 输出 tables/joins/filters/aggregations/group_by/order_by/limit/steps。
- 检查计划(程序化):计划表必须存在;"表.列"引用必须真实;每个维度/指标必须体现在计划文本;时间范围必须体现;有指标必须有聚合。发现问题自动重规划一次。

## 4. SQL 生成(阶段 5)

- 单次 LLM 生成一条只读 SQL;温度 0;`max_tokens=2800`(长 WITH 不截断)。
- **sql_hints 机制(M3.7)**:按关键词触发的 few-shot 口径示例注入生成提示。引擎仅提供通用机制(`QueryAgent(db_path, api_key, biz_context, sql_hints)`),券商口径示例由调用方注入(benchmark/run_eval.py 的 SQL_HINTS:持有→份额、增幅→绝对增量、科创→LIKE+分公司)。
- 提示约束:单 SELECT/WITH/EXPLAIN;表列必须来自给定结构;维度与实体标识列必须进 SELECT;编码维度同时输出 code 与 describe;禁止无关中间列。

## 5. 安全校验(阶段 6)

- 剥离注释(`--`、`/* */`);按分号切分语句(字符串字面量内分号不切);拒绝多语句。
- 仅放行 SELECT/WITH/EXPLAIN 开头;`WITH` 解析 CTE 后主语句动词(`_with_main_verb`),拒绝 `WITH ... DELETE/UPDATE/INSERT`。
- 执行层双保险:`file:...?mode=ro` + `PRAGMA query_only=ON`。

## 6. 执行与修复(阶段 7)

- 只读执行,单问最多取前 100 行(截断标注)。
- 执行失败自动修复一次:把 SQL + 错误信息回传 LLM,输出修正 SQL 再执行;再失败则兜底报错并记录 Trace FAIL。

## 7. 结果检查与解释(阶段 8-9)

- 结果检查(程序化):空结果(提示筛选过严/无数据)、单行、截断(注明前 N 行)。
- 解释:LLM 基于 问题+SQL+结果(前 20 行)+检查备注+默认假设,输出 3-6 句中文结论(结论先行、关键数字、假设与局限说明)。

## 8. 参数与模型

| 项 | 值 |
|---|---|
| 评测模型 | deepseek-chat(空响应实验结论;M3.7 起全量) |
| CLI 默认模型 | deepseek-v4-flash(可用环境变量 LLM_MODEL 覆盖) |
| 温度 | 0 |
| 端点 | https://api.deepseek.com(OpenAI 兼容) |
| 每调用超时 | 90s |
| 重试(M3.7 R9) | 超时/URLError/HTTP 429,5xx 指数退避 1.5s/3s,最多 3 次(纯调用层) |
| 理解/检索/计划输出上限 | 2000 tokens(JSON,失败重试 1 次) |
| SQL 输出上限 | 2800 tokens;解释 800 tokens |
| 结果展示上限 | 100 行;解释喂前 20 行 |
| 追问轮数 | 交互最多 3 轮,超轮转默认假设(clarify=False) |
