## 2. 关键解读(与本项目工作相关)

1. **sandbox 未启用**是此前大量工具被拦(如 "establish a concrete todo and acceptance criteria before this class of write")的根因:`sandbox.available=false`、`sandbox.bash=off`,而 `permission.mode=ask` 且 `allow_rules` 仅 1 条(即 reasonix.toml 里放行的那条 M1 测试命令)。后续新增 git 白名单后,`allow_rules` 应增加。
2. **两个模型均可用**:deepseek-flash(默认,deepseek-v4-flash,1M 上下文)与 deepseek-pro(deepseek-v4-pro)。与 text2sql 引擎使用 `.env.local` 的 `LLM_API_KEY`(OpenAI 兼容端点)是两套配置,互不影响。
3. **LSP 已启用但 servers=0**:本仓库以 Python 为主,当前无 LSP 服务器注册。
4. **sessions.count=0**:会话目录暂无记录(与本会话恢复机制相关的计数为 0)。
5. **两条 warnings**:`review` / `security-review` skill 声明了当前工具 registry 中不存在的 `use_capability`,调用这些 skill 前需注意能力缺失。
6. **git 可用性说明**:`git` 命令本身可用(v2.51.0),但宿主权限模式为 `ask` 且白名单只有 1 条,commit 类写操作可能被拦;已在 reasonix.toml 的 `[permissions] allow` 增加 `Bash=git` 白名单(见行动项)。
