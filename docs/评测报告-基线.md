- **M12(run1)/C08(run2)**:金标列全部命中,额外列仅脱敏姓名/展示类,数值逐值一致。

## 4. 规则变更记录(R1-R7)

- R1 口径启发式(已被 R7 收窄)。
- R2 数值以 gold 小数位先舍入再比 + 分桶标签规范化。
- R3 分级模型(M3,已被 R5 取代)。
- R4 多 CTE 幻觉误判修正。
- R5 全量统一 deepseek-chat。
- **R6 列名对齐比对**:金标列必须全部命中(常见同义别名归一);额外列仅限展示类(姓名/名称);单值题按值比对;对齐列数值性一致。
- **R7 单快照豁免限定 ads_cust_info_d**:仅当其出现在 expect_tables 时豁免其专属 token `20260531`,不再全局豁免时间检查。
