## 3. 未达标题(2 稳定 + 2 波动)

- **C02(稳定未达)**:仍用 `h.mkt_val>1000`(市值)而非 `SUM(hold_cnt)>1000`(份额),且缺"客户数"列——few-shot 注入后 LLM 仍部分忽略,长上下文口径遵守度是硬瓶颈。
- **C07(稳定未达)**:LIKE 与分公司维度已生效,但缺"客户数"列且张家港交易额 174,227,990.91 vs 金标 172,005,739.27(差 2.22M,疑似科创板存托凭证口径差异),需人工确认金标是否含存托凭证。
- **波动 2 题**:M11(输出 code 而非 describe)、C01(盈亏单列 vs 双列)。

- 简单 100% / 中等 96.5%(简单+中等综合 ~98%);复杂 79.2%(12 题中稳定通过 9-10 题)。
