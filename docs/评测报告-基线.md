## 3. 规则与模型变更记录

- R1 口径启发式:单快照/纯维度表豁免 `data_dt` 字面量检查。
- R2 结果比对:数值以 gold 小数位数为准先四舍五入再比;分组标签去"岁"/空白规范化。
- R3 分级模型策略(M3):复杂 chat / 简单中等 flash(已被 R5 取代)。
- R4 幻觉检查修正:多 CTE 不再误判为表幻觉。
- R5 全量统一 deepseek-chat:flash 随机空返回噪声大,中等对比 chat exec 14/14 vs flash 12/14;双跑取平均需稳定模型。
- E3 追问判据(引擎,question_specificity 自评字段):理解阶段新增 `question_specificity: clear|vague` 自评;`run()` 内 answerable 且 (vague 或 指标/维度/筛选/时间全空) 时 clarify=True 强制追问;E2 路径不受影响(E1-E9 全过,见 §5)。
- 宿主模型:reasonix.toml 已设 `default_model="deepseek-pro"`,并将两个 provider 的 `kind` 由 anthropic 改为 **openai**(与引擎同端点,零空返回错误的最有力证据);需重启会话生效。

## 4. chat arm result=False 系统性错误模式剖析(11 题)

**模式 A:列集合/列顺序偏差(5 题,数值全对,判定失分)**
M01(等级/数量列序颠倒)、M08(缺 up_prdt_type_name 列)、M12(多脱敏姓名列)、M14(缺 prdt_type_id 列)、C09(多脱敏姓名列)。
→ 对策(R6 下一步):结果比对改为**按列名对齐**而非按位置,多/少非关键展示列不再一票否决。

**模式 B:口径/单位/分桶边界错误(4 题,真错误)**
- C02:`h.mkt_val>1000`(市值)替代 `SUM(hold_cnt)>1000`(份额);且等级名"紫金理财钻石卡"缺"客户"后缀 → 客群为空。
- C04:"增幅"算成相对增幅率,金标是绝对增量(期末-期初)。
- C11:年龄分桶边界自创 30-39/40-49/50-59,金标 30-50/50-60/60+。
- C07:`prdt_type_name='科创板'`(等值)替代 LIKE '%科创%'(漏"科创板存托凭证")。

**模式 C:分组粒度/维度缺失(2 题,真错误)**
- C07:缺"分公司"维度,只按营业部名。
- C12:按 org_id 拆散同名营业部(张家港被拆两行),且缺"分公司"维度。

**模式 D:口径启发式过严(4 题 cal=0 但结果正确)**
M11、C05、C08、C12:客户表单快照(20260531)join 时省略 `data_dt` 被"必需时间字面量"误判。
→ 对策(R7 下一步):expect_tables 含 `ads_cust_info_d` 时豁免其专属 token `20260531`。

波动题:M01、M14(chat 输出列序/列集合随机变化,属模式 A)。
