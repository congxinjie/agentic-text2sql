# 数据库适配方案(生产库接入)

> 关联:评审"工程落地/可推广"。引擎不绑定 SQLite: 数据访问收敛到 `text2sql_demo/db_adapter.py` 的统一接口,
> 默认 `SqliteAdapter`(委托 `text2sql.py` 既有实现, 行为不变); 其它库由使用方注入自定义 adapter。
> **引擎保持零第三方依赖** —— 非 SQLite 驱动只在使用方代码里安装/导入。

## 1. 接口(最小三件套 + 可选查询计划)

| 方法 | 签名 | 说明 |
|---|---|---|
| `table_meta()` | -> {表名: [列名]} | 供计划层表/列真实性校验 |
| `schema_text(sample_rows, sensitive_columns, tables)` | -> str | DDL + 样例(受限字段打码); `tables` 供 RAG 只取候选表 |
| `run_query(sql, max_rows)` | -> (headers, rows, truncated) | **只读**执行 |
| `explain_plan(sql)` / `list_indexes()` / `analyze_plan(sql)` | 可选 | 查询优化; 默认返回空 |

基类 `BaseAdapter` 给出接口与默认空实现; `SqliteAdapter` 是默认实现。

## 2. 使用

```python
from text2sql import QueryAgent
from db_adapter import SqliteAdapter, make_adapter

agent = QueryAgent(db_path="xxx.db", api_key=load_api_key())          # 默认即 SQLite
agent = QueryAgent(db_path="xxx.db", api_key=key, db_adapter=SqliteAdapter("xxx.db"))  # 显式注入
```

`make_adapter(db_path, adapter)`: 传入 adapter 则原样返回; 传入含 `://` 的连接串(如 `mysql://...`)会**明确报错**并提示注入自定义 adapter, 避免把连接串当文件路径。

## 3. 接入 MySQL / PostgreSQL / Hive(示例; 驱动由使用方安装, 不进引擎)

```python
class MysqlAdapter(BaseAdapter):
    name = "mysql"
    def __init__(self, dsn):
        self.dsn = dsn
    def _conn(self):
        import pymysql  # 使用方自备驱动
        return pymysql.connect(host="...", user="readonly", password="...", database="...")
    def table_meta(self):
        # 查 information_schema.columns 返回 {表: [列]}
        ...
    def schema_text(self, sample_rows=2, sensitive_columns=None, tables=None):
        # 拼 DDL; sample_rows=0 时不取样例; sensitive_columns 打码
        ...
    def run_query(self, sql, max_rows=100):
        cur = self._conn().cursor()
        cur.execute(sql)
        rows = cur.fetchmany(max_rows + 1)
        return [d[0] for d in cur.description], rows[:max_rows], len(rows) > max_rows
```

查询优化可选实现 `explain_plan`(MySQL `EXPLAIN FORMAT=JSON` / PG `EXPLAIN`), 返回计划文本由引擎分类。

## 4. 安全与边界

- **只读**: 适配器必须用只读账号/只读连接; 引擎的 `validate_sql`(单条 SELECT/WITH/EXPLAIN)+ `_ast_check`(真实表列/AST 只读)再叠一层。
- **限流**: `run_query` 必须实现 `max_rows` 上限; 样例数据建议 `sample_rows=0`, 敏感列经 `sensitive_columns` 注入。
- **可追溯**: 结果只展示聚合/必要列; 日志只记表名/行数/耗时, 不记数据行。
- **CI**: 第 15 项 `db-adapter` 断言默认 SQLite 委托原实现(meta/schema/执行一致)、注入自定义 adapter 生效、非 SQLite 串明确拒绝(负对照)。

## 5. 当前边界

- 仓库内置的 `build_db.py` / `create_db.py` 仍是 SQLite 专用(建库脚本, 不属于引擎数据访问层)。
- MySQL/PG 适配器为**使用方按上述接口实现**, 仓库不内置第三方驱动(守零依赖铁律)。
