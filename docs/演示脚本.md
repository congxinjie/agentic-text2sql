# 演示脚本（M8 本地演示层 · 3–5 分钟分镜）

> 面向对象：非技术评委。演示入口是 `demo/server.py`（纯标准库本地服务）+ `demo/index.html`（中文单页）。
> 数据只读；口径经 `--biz-context demo/enterprise_biz.json` 注入，演示层不内嵌口径；API key 只在服务端读取，不进前端。

## 0. 启动（演示前 1 分钟）

```bash
# 项目主库（券商企业口径）
python demo/server.py --db "Agentic智能问数在客户营销场景的应用数据集/enterprise.db" \
                      --biz-context demo/enterprise_biz.json --port 8000
```

浏览器打开 `http://127.0.0.1:8000`。看到中文单页：顶部一句话说明、问题输入框、示例问题 chips。

## 2. 界面六要素（与 M8 退出标准对应）

| 要素 | 界面位置 | 关键词（curl 断言用） |
|---|---|---|
| ① 自然语言输入 | 顶部输入框 | 输入你的取数问题 |
| ② 结构化计划 | `details` ①，可展开 | 计划 |
| ③ SQL | `details` ② | SQL |
| ④ 结果表格 | `details` ③ | 结果 |
| ⑤ 口径说明与默认假设 | `details` ④ | 口径、假设 |
| ⑥ 失败自修复过程 | `details` ⑤ | 修复 |

## 3. 演示问答接口（无头可验证）

```bash
# 健康检查
curl -s http://127.0.0.1:8000/api/health

# 问答（POST JSON; GET 也支持 ?q=...&clarify=false）
curl -s -X POST http://127.0.0.1:8000/api/ask \
  -H "Content-Type: application/json" \
  -d '{"question":"各客户等级分别有多少客户?","clarify":false}'
```

返回 JSON 含：`question` / `answerable` / `sql` / `headers` / `rows` / `explanation` /
`plan` / `caliber_assertions` / `trace` / `error` / `elapsed_s` / `model`。
`trace` 中 `WARN`/`FAIL` 记录即为失败自修复过程。

## 5. 注意

- 演示全程只读；截图/录屏不得出现姓名、证件、联系方式等客户明细（引擎已按口径只输出聚合/脱敏字段）。
- 换库演示：同一条命令换 `--db` 即可（如 `customer_marketing_db/marketing.db`），不传 `--biz-context` 时走引擎默认语义。
- 若端口被占用：换 `--port 8001`。
- Windows 终端中文乱码时加 `PYTHONIOENCODING=utf-8`。
