## 演示操作清单(录屏用)

1. `cd text2sql_demo && streamlit run app.py` 打开 UI。
2. 点击示例 chips 或输入:
   - "各客户等级分别有多少客户?"
   - "2026 年一季度各产品一级分类的买入金额分别是多少?"
   - "2026-03-31 各客户等级中总资产最高的客户及其资产是多少?"
3. 输入 "帮我分析一下?" → 展示追问 → 补充 "按客户等级看总资产分布"。
4. 输入 "今天天气怎么样?适合买基金吗?" → 展示拒答。
5. 切 CLI:`python text2sql.py "华东地区有多少客户?"`(默认 demo 库)/ `--db` 指向 enterprise.db。
6. 打开 docs/评测报告-基线.md 展示指标表。

- 演示全程只读库;客户明细不出现姓名/证件/经纪客户号;结果截图无个人标识。
