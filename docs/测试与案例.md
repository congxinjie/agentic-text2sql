## 1. 简单题(3 例,单表单指标单筛选)

**S01 客户总数**
- 输入:"客户主档中共有多少客户?"
- 标准 SQL:`SELECT COUNT(*) AS c FROM ads_cust_info_d WHERE data_dt='20260531'`
- 标准答案:[[500]];Agent 双跑均 PASS(判定列名对齐 + 数值一致)。
- 真实 UI 自测(app_core 同路径):kind=ok,t=23.0s,rows=1。

**S09 总资产**
- 输入:"2026-03-31 全库客户总资产是多少?"
- 标准 SQL:`SELECT ROUND(SUM(nm_tot_aset+fc_pur_aset),4) AS 总资产 FROM dws_cust_aset_d WHERE data_dt='20260331'`
- 口径:总资产=nm_tot_aset+fc_pur_aset;取 20260331 快照。Agent 双跑 PASS。
- UI 自测:kind=ok,t=26.9s,rows=1。

**S13 交易笔数**
- 输入:"2026 年一季度客户交易笔数(买入+卖出)合计是多少?"
- 标准 SQL:`SELECT ROUND(SUM(buy_cnt+sell_cnt),0) AS 交易笔数 FROM dwd_cust_tran_d WHERE data_dt BETWEEN '20260101' AND '20260331'`
- Agent 双跑 PASS。

## 2. 中等题(3 例,join/多条件/时间范围)

**M01 客户等级分布(字典解码)**
- 输入:"各客户等级分别有多少客户?"
- 标准 SQL:`SELECT p.describe AS 客户等级, COUNT(*) AS 客户数 FROM ads_cust_info_d a JOIN dim_public p ON a.cust_lvl_cd=p.code AND p.code_type_id='100' WHERE a.data_dt='20260531' GROUP BY p.describe ORDER BY 客户数 DESC`
- 标准答案前 2:紫金理财银卡客户 151 / 紫金理财金卡客户 118。Agent 双跑 PASS。
- UI 自测:kind=ok,t=37.2s,rows=6。

**M08 产品一级分类买入金额**
- 输入:"2026 年一季度各产品一级分类的买入金额分别是多少?"
- 标准答案前 3:股票 1,381,320,301.62 / 开放式基金 929,399,333.48 / 理财产品 7,581,000.0。Agent 输出 [一级分类ID+名称+金额] 与金标逐值一致,M3.6 起 PASS(编码维度 code+describe 提示 + R8 别名)。

**M12 交易额前 10 客户**
- 输入:"2026 年一季度交易额(买入+卖出)前 10 的客户是哪些?"
- 标准 SQL 按 pty_id 分组取 top10;Agent M3.6 起 PASS(禁止无关中间列提示生效)。

## 3. 复杂题(3 例,多层聚合/窗口/口径易混)

**C01 全库盈亏(跨快照+资金流)**
- 输入:"2026 年一季度全库客户的盈亏合计是多少?"
- 标准 SQL:期初/期末资产快照 + 资金流入流出(队伍口径:盈亏=(期末-期初)+(流出-流入))。Agent M3.7 双跑 PASS(exec 100%)。

**C06 双客群交集**
- 输入:"2026 年一季度交易过招商银行相关产品、且 2026-03-31 持有中国平安相关产品的客户有多少人?"
- 标准 SQL:INTERSECT 两客群;Agent 双跑 PASS。

**C08 各等级最高资产客户(窗口)**
- 输入:"2026-03-31 各客户等级中总资产最高的客户及其资产是多少?"
- 标准 SQL:ROW_NUMBER() OVER (PARTITION BY 客户等级 ORDER BY 总资产 DESC);金标前 2:钻石卡 C000000000000004 59,662,230.46 / 白金卡 C000000000000150 4,775,602.76。Agent M3.6 起 PASS(实体标识列提示)。

## 7. 系统处理过程(可复现)

每次问答都按 9 阶段状态机执行(理解 → 检索 → 计划 → 检查计划 → 生成 SQL → 安全校验 → 只读执行 → 结果检查 → 解释),
每阶段的状态/耗时/说明写入 `Answer.trace`:

- **浏览器演示**:结果区「执行轨迹」折叠块,或顶部九阶段进度条 + 已用秒数(SSE,M10);
- **无头复现**:`POST /api/ask` 返回的 `trace` 字段,以及 `benchmark/runs/*.json` 里逐题的 `trace`;
- **失败自修复**:trace 中 `WARN` / `FAIL` 记录即为"执行失败 → 自动修复一次"的真实过程。
